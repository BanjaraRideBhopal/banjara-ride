## 1. Goal

Many vehicles in the Banjara Ride fleet are owned by external vendors who have attached their vehicles to the business. At month end, Banjara Ride needs to know how much rent revenue to share with each vendor per vehicle.

This phase introduces:
1. A `vendors` table and `vendor_vehicles` table linking vehicles to vendors with a revenue share percentage
2. A new **Vendor Payouts** tab in the app (super_admin only) showing a month-wise revenue sharing statement per vendor
3. The statement mirrors the format of the attached Excel sheet

### 4.1 `vendors`

```sql
CREATE TABLE vendors (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  phone TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

Seed: 15 vendors from §3 (including BanjaRide LLP).

### 4.2 `vendor_vehicles`

Links each vehicle registration to a vendor with a revenue share percentage and a parking charge deduction.

```sql
CREATE TABLE vendor_vehicles (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  vehicle_id BIGINT NOT NULL REFERENCES vehicles(id),
  vendor_id BIGINT NOT NULL REFERENCES vendors(id),
  owner_share_pct NUMERIC NOT NULL,  -- e.g. 0.5 = 50%
  parking_charge NUMERIC NOT NULL DEFAULT 1000,  -- monthly fixed deduction
  attached_date DATE,                -- reg date from sheet (Excel serial → real date)
  active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE (vehicle_id)  -- one vendor per vehicle at a time
);
```

Seed: all 57 vehicles from the sheet mapped to their vendors with correct `owner_share_pct` and `attached_date`.

**Excel serial date conversion:** The sheet stores dates as Excel serial numbers (e.g. 46217 = today's row date, 44900 = registration date). Convert to real dates:
```python
# Excel serial 1 = 1900-01-01, but Excel has a leap year bug so offset is 25569 from unix epoch
from datetime import date, timedelta
def excel_to_date(serial):
    return (date(1899, 12, 30) + timedelta(days=int(serial))).isoformat()
```

### 4.3 RLS for new tables

```sql
-- vendors: all authenticated can read; super_admin can write
ALTER TABLE vendors ENABLE ROW LEVEL SECURITY;
CREATE POLICY "read_all" ON vendors FOR SELECT TO authenticated USING (true);
CREATE POLICY "super_admin_write" ON vendors FOR ALL TO authenticated
  USING (is_super_admin()) WITH CHECK (is_super_admin());

-- vendor_vehicles: all authenticated can read; super_admin can write
ALTER TABLE vendor_vehicles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "read_all" ON vendor_vehicles FOR SELECT TO authenticated USING (true);
CREATE POLICY "super_admin_write" ON vendor_vehicles FOR ALL TO authenticated
  USING (is_super_admin()) WITH CHECK (is_super_admin());
```

## 5. Revenue Sharing Formula

Per vehicle per month, matching the sheet column structure:

```
Credit (Gross Rent)     = SUM(final_rent) for all status='end' bookings
                          for this vehicle_number in the selected month

GST 6%                  = Credit × 0.06
Credit after GST        = Credit − GST 6%
Parking Charge          = fixed monthly deduction (from vendor_vehicles.parking_charge, default ₹1000)
Maintenance Debit       = SUM(amount) from maintenance_expenses for this vehicle in the month
Amount Left             = Credit after GST − Parking Charge − Maintenance Debit
Owner Share %           = vendor_vehicles.owner_share_pct
Owner Amount            = Amount Left × owner_share_pct
BJ Earn                 = Amount Left − Owner Amount  (Banjara Ride's share)
```

Note: `final_rent` is used (not `full_amount_received`) — it represents actual earned rent including deductions, which is correct for revenue sharing. Security deposits are excluded (they are refundable, not revenue).

## 7. Data Fetching Strategy

All fetched in parallel on mount and filter change:

```js
const [bookings, expenses, vendorVehicles] = await Promise.all([
  supabase.from('bookings')
    .select('vehicle_number, final_rent, booking_date, status')
    .eq('status', 'end')
    .gte('booking_date', monthStart)
    .lte('booking_date', monthEnd),

  supabase.from('maintenance_expenses')
    .select('vehicle_id, amount, expense_date, vehicles(registration_number)')
    .gte('expense_date', monthStart)
    .lte('expense_date', monthEnd),

  supabase.from('vendor_vehicles')
    .select('*, vehicles(id, registration_number, vehicle_type_id, vehicle_types(name)), vendors(name)')
    .eq('active', true),
]);
```

All calculations done in JS after fetch — no DB aggregation functions needed.

Match bookings to vendor_vehicles via `booking.vehicle_number === vehicle.registration_number`.
Match expenses to vendor_vehicles via `expense.vehicle_id === vehicle.id`.
